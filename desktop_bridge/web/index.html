串接指南

選擇模型，複製範例，讓你的服務開始對話。

1. 設定 API 入口

BASE URL
Authorization: Bearer YOUR_API_KEY

使用已保存的 API 金鑰，並設定環境變數 LLM_BRIDGE_KEY。既有金鑰無法再次顯示。

2. 選擇可用模型

依目前模型設定列出；實際可用性取決於金鑰權限與訂閱。登入狀態不代表已取得所有模型權限。

3. 測試連線

透過上方 Base URL，依序向 Claude 與 Codex 各發送一筆測試訊息。

金鑰僅用於當次測試，送出後清空輸入框，不保存到設定或紀錄。每個來源最多等待 60 秒；測試會使用少量訂閱額度。

尚未測試。回應時間包含網路傳輸、排隊與模型推論。

4. 複製呼叫範例

範例從環境變數讀取金鑰，使用合成訊息驗證回應。

Chat 使用 messages；Jev Decisions 保留 state／questions，回傳 answers。模型能力查詢不推論，模型測試會消耗用量。機率為一般 LLM 估計，既有門檻需重測。不支援串流與非等價的取樣參數。請保持 Bridge 執行中，且對應的 CLI 訂閱已登入。
